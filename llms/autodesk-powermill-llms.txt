# Autodesk PowerMill

> Autodesk PowerMill is CAM software for high-speed and 5-axis CNC machining, used in aerospace,
> automotive, mould and die, and precision engineering to generate toolpaths for complex parts.
> It is installed Windows desktop software. It has NO web API, NO OpenAPI/GraphQL/AsyncAPI contract,
> and NO hosted endpoint an agent can call. Its programmable surface is local automation: macro
> commands executed inside a running PowerMill session, and an in-process .NET/COM object model that
> drives that session on the same machine. Anything that needs PowerMill needs a licensed PowerMill
> installation to talk to.

Generated by API Evangelist on 2026-09-06 from this provider profile and the artifacts in it.

## What you can actually call

- [PowerMill Macro API](https://help.autodesk.com/view/PWRM/2026/ENU/): macro (.mac) files of PowerMill
  commands. Every UI action maps to a command; a macro replays those commands. Local only.
- [PowerMill .NET / COM API](https://github.com/Autodesk/PowerShapeAndPowerMillAPI): the
  `Autodesk.ProductInterface.PowerMILL` object model (PMAutomation + PM* entity collections). Starts,
  drives and queries an installed PowerMill session over COM from C# or VB.NET. MIT licensed.
- There is no PowerMill Python API. Autodesk publishes no Python binding, no PyPI package and no
  Python guide in the PowerMill help tree; the only route from Python is shelling out to a macro.
